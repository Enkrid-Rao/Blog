# 关于本站

这是一个用 MkDocs Material 构建的个人笔记站点，主要用于记录数学、物理、编程等领域的学习内容。

## 本站特色

- **霞鹜文楷**字体带来手写笔记的温暖质感
- **MathJax 3** 渲染 LaTeX 公式，行间公式带有浮动显示效果
- **6 种配色主题** + **3 档显示模式**自由组合，适应不同光线环境
- 开源免费，代码托管在 [GitHub](https://github.com/Enkrid-Rao/Blog)

## 致谢

- [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) — 强大优雅的文档框架
- [MathJax](https://www.mathjax.org/) — 高质量数学公式渲染
- [霞鹜文楷](https://github.com/lxgw/LxgwWenKai) — 优美的开源中文字体
